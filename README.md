# The Farmer Was Replaced Scripts

A collection of reusable Python automation scripts created whilst playing **The Farmer Was Replaced**.

All these scripts were created as a way of practicing/implementing Python, which gradually developed into more complex automation involving multiple drones, grid traversal, sorting and reusable functions.
Within the scripts, there is light use of open-source mathematics and structure designed specifically for this game within the TFWR community and has been highligted within their respective scripts at the start.

## Features

* Automated farming for all crops/entities throughout the game
* Single-drone and multi-drone automation
* Grid and farm traversal scripts to map drone schema
* Cactus sorting using Cocktail Shaker Sorting algorithm
* Automated maze navigation for end game resource collection
* Pumpkin-specific utilities and calculations
* Reusable planting and farming functions
* Automated / AFK farming scripts

## Concepts & Algorithms

The project gave me practical experience with:

* Python functions, loops and conditionals
* Lists, dictionaries and other data structures
* Modular programming and code reuse
* Grid traversal and coordinate systems
* Sorting algorithms such as the Cocktail Shaker Sort
* State-based decision making
* Multi-drone workload distribution
* Algorithmic problem solving and optimisation

The **Solo Drone** and **Multi Drone** scripts contain the main farming algorithms, while the utility files contain reusable functionality used across different farms.
